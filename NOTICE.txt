The following transitive dependencies are flagged by automated license scanners but require no
action; each is bundled inside aws-cdk-lib (not a dependency this repo pins or can independently
swap) and is either dual-licensed with an approved option or under a permissive license the
scanner's default allowlist doesn't yet recognize:

- case@1.6.3 (via aws-cdk-lib) - dual-licensed "(MIT OR GPL-3.0-or-later)". This repo consumes it
  under the MIT branch, which a dual license permits by definition, so there is no copyleft
  obligation. Flagged as GPL by scanners that don't parse SPDX "OR" expressions.
- minimatch@10.2.5 (via aws-cdk-lib) - BlueOak-1.0.0, a modern OSI-style permissive license
  (functionally equivalent to MIT/BSD-2-Clause), not yet on some scanners' approved-license list.
  The dev-only jest tooling also resolves minimatch@10.2.6 (BlueOak-1.0.0) and minimatch@9.0.9
  (ISC); neither ships in the synthesized template.

Both flagged packages are vendored inside aws-cdk-lib's own dependency tree; forcing a different resolved
version via npm overrides would risk breaking AWS CDK's internals for no legal benefit and is not
done here. Track scanner-allowlist updates separately; no code or dependency change is required.
